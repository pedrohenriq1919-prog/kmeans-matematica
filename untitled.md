# K-Means aplicado à Matemática

Projeto de aprendizado de máquina não supervisionado cujo objetivo é
compreender matematicamente e implementar o algoritmo K-Means.

## Objetivos

- compreender clustering;
- representar dados matematicamente;
- trabalhar com features;
- compreender distância euclidiana;
- compreender centróides;
- implementar K-Means manualmente;
- comparar a implementação manual com Scikit-Learn;
- analisar a escolha de K.
